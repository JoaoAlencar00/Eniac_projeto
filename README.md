# ENIAC nas Comunidades

Landing page de apresentação do projeto **ENIAC nas Comunidades**, com informações sobre a iniciativa, público-alvo e formulário visual de inscrição.

[Acessar a página publicada](https://eniac-projeto.vercel.app/)

## Tecnologias e recursos

- HTML para estrutura e conteúdo.
- CSS para cabeçalho, seções, galeria, formulário e rodapé.
- Galeria de imagens com seleção por botões.
- Campos de inscrição com validações nativas do HTML.

## Como visualizar localmente

Clone o repositório e abra a pasta em um editor com servidor de desenvolvimento, como a extensão Live Server do VS Code:

```bash
git clone https://github.com/JoaoAlencar00/Eniac_projeto.git
cd Eniac_projeto
```

Sirva a **raiz do repositório** e abra `index.html`. Os caminhos de estilos e imagens começam na raiz do servidor, por isso a abertura direta por `file://` pode não carregar todos os recursos.

## Organização

- `index.html`: página principal.
- `Front End/`: estilos utilizados pela página e uma cópia do HTML.
- `assets/`: imagens e elementos visuais.
- `Back End/script.js`: arquivo JavaScript reservado, atualmente sem implementação.

## Escopo

A versão atual é uma página estática. O formulário apresenta a interface e a validação do navegador, mas não envia inscrições para uma API nem persiste dados.

O conteúdo e a identidade visual apresentados fazem referência ao ENIAC e ao projeto ENIAC nas Comunidades.
